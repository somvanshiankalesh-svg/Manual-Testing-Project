
# Manual Testing Project

## 📌 Project Overview
This repository contains my Manual Software Testing practice work. It includes test scenarios, test cases, test execution details, and bug reports created to understand and practice real-world software testing concepts.

## 🎯 Project Objectives
- Understand the Software Testing Life Cycle (STLC).
- Create and execute manual test cases.
- Identify and report software defects.
- Practice positive and negative testing.
- Understand functional and UI testing.
- Improve test documentation skills.

## 🧪 Testing Activities
- Requirement Analysis
- Test Scenario Preparation
- Test Case Design
- Test Case Execution
- Bug Reporting
- Retesting
- Regression Testing
